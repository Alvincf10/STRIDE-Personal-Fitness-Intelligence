## Working summary

- **Name:** STRIDE
- **User:** single personal user
- **Device:** Garmin Forerunner 165
- **Integration:** Garmin Connect Personal API (scheduled pull)
- **Intelligence:** deterministic, explainable; no LLM for training decisions
- **Six signatures:** Smart Running Coach · Personal Baseline / Running DNA · Journey & Gamification · Performance Lab · Recovery Intelligence · Race Predictor & Goals
